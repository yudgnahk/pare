## 3. Per-PR evidence

### #50: in-use gate (ACCEPT-WITH-FOLLOWUP)
`git diff origin/master...refs/peer/pr50`, tip `origin/integration/2026-10-07`
- **Every entry point.** `quickClean`/`deepClean` → `clean`. The gate is the last check before Trash and also runs on dry runs (`CleanupEngine.swift:468-474`). No other trash path handles findings (`git grep trashItem`).
- **lsof failures.** Timeout (10 s), non-zero exit with partial output, missing binary, non-UTF-8 output, or output without a `p<pid>` record all → `nil` (`ToolCommandRunner.swift:58-63,104-127`, `OpenFileSnapshot.swift:37-42,86-91`).
  - `nil` fails closed for running-app caches, SQLite under Caches, `*.incomplete` and (after 119013b) dependency folders.
  - Other items go ahead with an "unavailable" flag on the result card (`InUseGate.swift:44-60`). This is the documented design (`docs/architecture/cleanup-safety.md` gate 9).
- stdout is drained on GCD and stderr goes to /dev/null, so there is no pipe deadlock.
- Keys go through `canonicalPathKey` and ancestors are indexed by component.
- **H3:** `OpenFileSnapshot.swift:23-26` indexes the raw `n` value. The `\xNN` decoder exists (`DeletedOpenFilesRule.swift:144,153-155`, from #51) but is not reused. See §5.
